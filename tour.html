Why Sudhaar · a 1-minute tour

Sarvam ships fast. Code falls behind.

Every few months a Sarvam model or voice is retired. Code written against the old docs, or by an AI assistant from old memory, then gets 400 Bad Request. Usually nobody notices until a demo breaks.

What Sudhaar does

1 · FindEvery Sarvam call in a repo or pasted code that will fail today
2 · ProveA tiny real call to Sarvam’s API: 400 now, 200 with the fix
3 · FixRewrites the call and shows you the diff
4 · LearnSarvam-105B reads Sarvam’s changelog; the live API confirms each new rule

Agent Skills teach AI assistants how to use Sarvam. Sudhaar verifies that the code actually works.
